# ChatApp

A peer-to-peer chat application I developed in C# and .NET Framework. The application enables direct communication between two users without requiring a central server or user accounts. A demo of the application with Swedish commentary is available at: https://www.youtube.com/watch?v=Xei_ZH5ZqjQ&feature=youtu.be
 
## Features
 
- Peer-to-peer communication using IP addresses and port numbers
- Text-based messaging between connected users
- WPF graphical user interface
- MVVM architecture
- Persistent conversation history stored locally using JSON/XML
- Conversation search functionality implemented with LINQ
- Custom JSON-based communication protocol
- Asynchronous network communication using sockets and tasks/threads
- Error handling with custom exceptions
 
## Technologies
 
- C#
- .NET Framework
- WPF
- MVVM
- System.Net.Sockets
- LINQ
- JSON/XML
